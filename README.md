# 🎓 AI Student Tutor

🚀 An AI-powered web application that helps students learn smarter.

## ✨ Features

* 📊 Diagnosis system (identify weak areas)
* 📅 Personalized study planner
* 🤖 AI Tutor (explains topics clearly)
* 📝 Mock test system

## 🛠 Tech Stack

* Python (Flask)
* HTML, CSS
* OpenRouter API

## ▶️ Run Locally

pip install -r requirements.txt
python run.py
